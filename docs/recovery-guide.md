# eslee폴더잠금기 복구 가이드

eslee폴더잠금기 복구 도구는 메인 앱이 삭제되었거나 중단되었거나 일반 잠금 해제로 복구할 수 없을 때 ACL 백업을 이용해 원래 권한을 되돌리는 독립 실행 도구입니다.

프로그램 파일을 삭제해도 이미 적용된 Windows ACL 규칙은 자동으로 제거되지 않습니다. NTFS 권한은 파일 시스템에 남아 있으므로 복구 도구나 Windows 권한 편집으로 명시적으로 복구해야 합니다.

## 마스터 복구 비밀번호 인증

v1.2.0부터 복구 도구는 실행 즉시 마스터 복구 비밀번호 인증을 요구합니다.

- 인증은 복구 도구 프로세스 자체에서 수행합니다. 메인 앱을 거치지 않고 실행 파일을 직접 실행해도 반드시 비밀번호를 입력해야 합니다.
- 인증에 성공하기 전에는 잠긴 폴더 경로, ACL 백업 목록, 파일명, 백업 생성 시각, 복구 명령, 상세 로그를 표시하지 않습니다.
- 입력 실패 횟수 제한이 없습니다. 틀리면 즉시 다시 입력할 수 있습니다.
- `F1` 키로 설정된 힌트를 볼 수 있고, `ESC` 키로 종료할 수 있습니다.
- 비밀번호는 명령줄 인수, 환경 변수, 파일로 전달할 수 없으며 오직 화면 입력만 받습니다.

마스터 복구 비밀번호가 설정되지 않았다면 먼저 메인 앱에서 설정해야 합니다. 마스터 보안 데이터가 손상된 상태에서는 기존 백업을 보호하기 위해 복구 도구 사용이 차단됩니다.

**마스터 복구 비밀번호를 잊으면 복구 도구를 사용할 수 없습니다.** 개발자도 확인하거나 초기화할 수 없고, 복구 코드가 없으며, 재설치해도 초기화되지 않습니다.

## 실행 방법

1. 메인 앱의 `복구 도구 열기` 버튼을 누르거나, 시작 메뉴의 복구 도구 바로가기 또는 설치 폴더의 `eslee폴더잠금기_복구도구.exe`(영어 빌드: `eslee-folder-locker-recovery.exe`)를 실행합니다.
2. UAC 승격을 승인합니다.
3. 마스터 복구 비밀번호를 입력합니다.
4. 복구할 잠금 대상을 선택합니다.
5. 사용할 ACL 백업 파일을 선택합니다.
6. 대상 경로, 백업 파일, 복구 항목 수를 확인합니다.
7. `RESTORE`를 입력해 복구를 실행합니다.

내부 호환성을 위해 빌드 산출물에는 `FolderGate.RecoveryTool.exe`가 함께 남을 수 있습니다. 사용자 안내와 배포 파일명은 언어별 alias를 기준으로 합니다.

## 주의 사항

- 복구 도구는 관리자 권한이 필요합니다.
- 설치형 기준 백업 파일은 `%LOCALAPPDATA%\eslee-folder-locker\backups` 아래에 저장됩니다. 개발/포터블 구조에서는 `<루트>\data\backups`입니다.
- 백업 파일이나 `security` 폴더의 마스터 보안 데이터를 삭제하면 자동 ACL 복구가 어려워질 수 있습니다.
- 프로그램을 제거해도 이 데이터는 삭제되지 않으며, 재설치하면 다시 인식됩니다.
- 복구 후에도 문제가 남으면 Windows 보안 속성의 고급 권한 편집 화면에서 ACL을 직접 점검해야 합니다.
