# eslee폴더잠금기 한계

- eslee폴더잠금기는 암호화 도구가 아닙니다.
- 관리자 권한이 있거나 NTFS ACL을 이해하는 사용자를 완전히 막는 보안 경계가 아닙니다.
- 빠른 모드는 폴더 루트 접근 차단용입니다. 경로와 ACL 구조를 아는 사용자는 일부 상황에서 우회할 수 있습니다.
- 강화 모드는 항목 수가 많은 폴더에서 시간이 오래 걸릴 수 있습니다.
- reparse point, junction, symbolic link 내부로는 안전을 위해 따라가지 않습니다.
- ACL 변경이 중단되면 앱의 복구 기능이나 `eslee폴더잠금기_복구도구.exe`를 사용해야 합니다.
- `%LOCALAPPDATA%\eslee-folder-locker\backups`(개발/포터블: `data\backups`)의 ACL 백업 파일을 삭제하면 자동 복구가 어려워질 수 있습니다.

## 마스터 복구 비밀번호의 보안 한계

마스터 복구 비밀번호는 복구 도구의 위치만 아는 일반 사용자의 무단 접근을 막기 위한 기능입니다. 다음은 막지 못하며, 이를 넘어서는 보호를 주장하지 않습니다.

- 같은 Windows 계정에 로그인해 관리자 권한을 얻을 수 있는 사용자는 보안 파일을 조작하거나 ACL을 직접 편집해 우회할 수 있습니다.
- 디버거나 바이너리 변조 능력이 있는 공격자는 검증 로직 자체를 우회할 수 있습니다.
- ACL 백업 파일은 암호화되지 않습니다. 백업 암호화는 복구 최후 수단인 백업의 가용성을 해칠 수 있어(보안 데이터 손실 시 백업 전체가 복구 불능이 되는 문제, 승격 도우미에 키를 전달할 안전한 경로 부재) v1.2.0에서는 채택하지 않았습니다. 대신 보안 파일의 Windows ACL을 현재 사용자, SYSTEM, Administrators로 제한합니다.
- 검증 데이터는 PBKDF2-SHA256 단방향 verifier로만 저장되며 비밀번호 원문은 저장되지 않습니다.
- 보안 파일이 삭제·손상·교체된 경우 이를 감지해 새 잠금과 복구 도구 사용을 차단하지만, 같은 계정의 공격자가 설정 파일과 보안 파일을 동시에 일관되게 조작하는 것까지 막을 수는 없습니다.
- 힌트는 평문으로 저장됩니다. 힌트에 비밀번호를 적으면 이 보호는 무의미해집니다.

## 마스터 복구 비밀번호 분실

- 마스터 복구 비밀번호를 잊으면 복구 도구를 사용할 수 없습니다.
- 복구 코드, 비밀번호 찾기, 개발자 초기화, 재설치를 통한 초기화는 제공되지 않습니다. 의도된 동작입니다.
- 이 경우에도 폴더 비밀번호를 이용한 일반 잠금 해제는 계속 동작하므로, 모든 폴더를 완전 해제한 뒤 데이터 폴더를 정리하고 새로 시작하는 것은 가능합니다.
